## Описание

MetricsApp — веб-приложение для загрузки пользовательских датасетов
и автоматического вычисления бизнес-метрик цифровых продуктов
с интерактивной визуализацией результатов.

## Функциональность

- Регистрация и аутентификация пользователей (JWT в куках)
- Ролевая модель доступа: admin, analyst, viewer
- Создание проектов и управление ими
- Загрузка файлов данных в формате CSV и JSON
- Автоматическое распознавание столбцов загруженного файла
- Вычисление 7 бизнес-метрик через SQL-запросы в PostgreSQL:
  - Revenue — суммарная выручка
  - ARPU — средняя выручка на пользователя
  - LTV — ценность клиента
  - DAU/MAU — соотношение ежедневной и ежемесячной аудитории
  - Retention Rate — удержание пользователей
  - Churn Rate — отток пользователей
  - Conversion Rate — конверсия
- Визуализация метрик через Chart.js (линейные, столбчатые, кольцевые графики)
- Экспорт результатов в CSV
- Панель администратора для управления пользователями

## Технологический стек

- **Backend:** Python, Flask, SQLAlchemy ORM
- **База данных:** PostgreSQL (драйвер psycopg)
- **Аутентификация:** JWT (python-jose), Werkzeug
- **Шаблонизатор:** Jinja2 (SSR)
- **Визуализация:** Chart.js
- **Обработка данных:** Pandas

## Установка и запуск

### Клонировать репозиторий

```bash
git clone https://github.com/SemyonKvakin/WebAnalytics.git
cd WebAnalytics
```

### Создать виртуальное окружение и установить зависимости

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

### Настроить подключение к базе данных

В файле `database.py` указать свои данные:

```python
DATABASE_URL = "postgresql+psycopg://postgres:ВАШ_ПАРОЛЬ@localhost:5432/metrics_db"
```

### Создать базу данных в PostgreSQL

```sql
CREATE DATABASE metrics_db;
```

### Инициализировать базу данных

```bash
python init_db.py
```

Создаст все таблицы и пользователя-администратора:
- Логин: `admin`
- Пароль: `Admin123!`

### 6. Запустить приложение

```bash
python app.py
```
